# S2-E sources and preservation

No new downloads, dependencies, software, services or paid assets.

- Approved S2-D `market-street-optimized.glb`: **unchanged bytes**, building meshes/materials/floors/orientation preserved. Underlying S2-A/B/C native files and evidence remain unchanged.
- Original environment components retain the provenance in [S2-C](../market-street-s2c/ASSET-RECORD.md) and [S2-D](../market-street-s2d/ASSET-RECORD.md): Kenney Modular Buildings windows and Quaternius Stylized Nature MegaKit canopy/fern geometry, CC0-1.0, with original license files retained. Sixteen toe-planter ferns reuse the already licensed source geometry/UVs; no new pack was acquired.
- New footings, retaining tiers, columns, bracing, bearers, stairs, bridge, ramp, guards, planting supports and collision references are original project geometry authored in the independent S2-E Blender scene through live Blender MCP.
- The exact R0-A3 top-mesh reference is a read-only copy of existing project geometry, not replacement terrain. Browser rendering reuses the actual existing island implementation unchanged.
- Four standalone imported canopy transforms align to actual ground **only in the S2-E native scene and browser overlay**. The original model file is untouched. Building transforms, plaza planting and original island vegetation are unchanged.
- Comparison sheets arrange unchanged real render/capture pixels. They are not generated concept illustrations.

`baseline-hashes.json` and `validation.json` verify 1,430 protected files. `site-manifest.json` records terrain contacts, guard proxies, route heights and the four vegetation transforms. Original licenses and attribution requirements remain intact. No production assets are replaced or deployed.
